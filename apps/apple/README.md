# Atelier Apple apps

This directory contains the five Apple clients as multi-destination SwiftUI
applications generated by XcodeGen. Each target supports iPhone, iPad, and
macOS from one source entry point.

## Requirements

- Xcode 16 or newer
- XcodeGen 2.38 or newer
- iOS/iPadOS 17 and macOS 14 deployment targets

## Generate and build

```sh
cd apps/apple
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer \
  xcodebuild -project Atelier.xcodeproj -scheme Atelier \
  -destination 'platform=macOS' build

cd Packages/AtelierShared
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test
```

The current app content comes from `MockLocalWorkspaceRepository`. It is
intentionally local-only and never reports a provider, PDS, or collaboration
service as connected. Replace that repository through the interfaces in
`AtelierPersistence` as real storage and sync services are introduced.

## Modules

- `AtelierCore`: product identity, workspace models, and offline status.
- `AtelierContracts`: public-PDS and cross-client record contracts.
- `AtelierPersistence`: local repository boundary and named local mock.
- `AtelierCollaboration`: collaboration protocol and engine boundary.
- `AtelierEditor`: Markdown document model and native editor surface.
- `AtelierDesign`: shared color and component tokens.
- `AtelierAppUI`: adaptive shell shared by all five app targets.
