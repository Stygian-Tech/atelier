title: Atelier Home
---

> This page describes the MVP contract. The bootstrap Home surface is a local
> preview and has no authenticated cross-product search or command execution.

Home composes Today, Inbox, Projects, global search, commands, and saved views from the records owned by each focused product. It does not create a second canonical store.

Cross-app commands create explicit typed relationships: Mail → Task, Event → Note, Note action → Task, and any record → Project.
