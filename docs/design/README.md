# Atelier design source

`atelier-marketing-concept.png` is the initial visual implementation reference
for the marketing site and shared web tokens. It evolves the existing Atelier
Mail palette: warm paper `#fffaf7`, ink `#242120`, coral `#ff6542`, cyan
`#1fb8ca`, pale yellow `#fff0a8`, border `#eadeda`, and compact 8px radii.

Product UI remains code-native. Final app icons and store artwork require an
explicit visual review before submission.
